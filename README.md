# SS Finder

ガソリンスタンドを店舗名（一部でも可）で検索し、基本情報・地図・ストリートビューを表示して、最大3件まで横に並べて比較できる Web アプリです。

- HTML / CSS / JavaScript だけで動く静的サイトです（ビルド不要）。
- Google の **Places API (New)** と **Maps Embed API** を使います。
- 仕様は [REQUIREMENTS.md](REQUIREMENTS.md)、開発ルールは [CLAUDE.md](CLAUDE.md) を参照してください。

## できること

| 機能 | 内容 |
|---|---|
| 検索 | 店舗名や地名で検索。「店名で探す」と「場所で探す（ガソリンスタンドに限定）」を同時に行い、店名で当たったものを先に出す |
| 基本情報 | 住所・電話・営業時間・営業状況・定休日・ブランド・評価・公式サイト・Google マップへのリンク |
| 地図・ストリートビュー | 表示中の店舗を埋め込み表示 |
| 候補一覧 | 上位4件をカード、残りは名前で表示。押すと表示を切り替え |
| 比較 | 最大3件を横並びで比較。× で外す |
| 検索履歴 | 見つかった検索を新しい順に20件まで保存。押すと再検索 |
| お気に入り | ☆ で追加・外す。一覧から表示。JSON でエクスポート/インポート |

### 取れない・推定している項目

- **ブランド**：API に項目が無いため、店名から推定しています（例：「ENEOS（店名から推定）」）。
- **定休日**：週の営業時間から「開いている時間が無い曜日」を求めています。祝日や臨時休業は反映されません。
- **運営会社**：API に項目が無いため、常に「—」です。

### 検索のしくみと注意

- Google には、ガソリンスタンドなのに「建物」などの種類で登録された店があります（例：京都市左京区の「Ｅｓｓｏ天王町ＳＳ」）。そのため、1回の検索で次の3通りを同時に行い、結果を合わせています。
  - **店名で探す**：入力のまま探す。
  - **別の言い方で探す**：カタカナのブランド名を Google の登録の綴りに直し（エッソ→Esso など）、「SS」が無ければ足して探す（例：「天王町」→「天王町 SS」）。
  - **場所で探す**：ガソリンスタンドに絞って探す。地名だけの入力には「ガソリンスタンド」を足す。
  - 店名で探した結果のうち、名前に「SS」「石油」やブランド名を含む店か、ガソリンスタンドとして登録された店だけを残し、先に表示する。
- **都道府県（任意）**：選ぶと、検索語の先頭に付けて探し、その都道府県の住所の店だけを表示します。同じ名前の店や地名が各地にあるときは、選ばないと別の地域の店が出やすくなります（例：「天王町」は京都府を選ぶと Ｅｓｓｏ天王町ＳＳ が先頭に出ますが、指定なしでは横浜や東京の店が出ます）。
- **1回の検索で、Google の検索を最大3回使います。** 1日の回数上限を設定している場合は、その3分の1ほどの回数しか検索できません。

## 準備：Google Maps の API キー

1. [Google Cloud コンソール](https://console.cloud.google.com/) でプロジェクトを選び、請求先アカウントを有効にする。
2. 「API とサービス」→「ライブラリ」で次の2つを有効にする。
   - Places API (New)
   - Maps Embed API
3. 「認証情報」で API キーを作り、**必ず制限をかける**。
   - **API の制限**：上の2つだけに絞る。
   - **ウェブサイトの制限**：使う URL だけを許可する。
     - 手元で試す用：`http://localhost:5500/*`
     - GitHub Pages 用：`https://<ユーザー名>.github.io/Shin_ss-finder/*`
4. 使いすぎ防止に、次の2つを設定しておくと安心です。
   - 「割り当て」で、1日の回数上限を設定する（例：検索・詳細取得それぞれ1日30回）。
   - 「お支払い」→「予算と上限」で、予算の通知を作る。

> キーの文字列は、コードや README に書かないでください。公開リポジトリに載ると誰でも使えてしまいます。

## 手元で動かす

ビルドは不要です。`docs/` フォルダを、ポート 5500 の簡単な Web サーバーで配信します。
ファイルを直接ダブルクリックして開く（`file://`）と、JavaScript のモジュールが読み込めないため動きません。

**方法 A：VS Code の拡張機能「Live Server」**（初期設定のポートが 5500）

1. VS Code で `docs/index.html` を開く。
2. 右下の「Go Live」を押す。

**方法 B：コマンド**（Node.js が必要）

```powershell
npx http-server docs -p 5500 -c-1
```

ブラウザで http://localhost:5500 を開きます。

### API キーの渡し方（どれか1つ）

優先順位の高い順に読み込みます。

1. URL に付ける：`http://localhost:5500/?gmaps_key=キー`（ブラウザに保存したあと、URL からは自動で消えます）
2. 画面右上の「APIキー設定」から入力して保存（このブラウザの中にだけ保存されます）
3. `docs/config.example.js` をコピーして `docs/config.js` を作り、キーを書く（`config.js` は `.gitignore` 済みで、GitHub には上がりません）

## GitHub Pages で公開する

1. 変更を `main` ブランチに入れて GitHub に push する。
2. GitHub のリポジトリで「Settings」→「Pages」を開く。
3. 「Build and deployment」で Source を「Deploy from a branch」、Branch を `main`、フォルダを `/docs` にして保存する。
4. 数分後、`https://<ユーザー名>.github.io/Shin_ss-finder/` で公開される。
5. 開いた画面の「APIキー設定」からキーを入力する。

## 動作確認の手順

API キーを設定した状態で、上から順に試します。本物の検索は、1回ごとに1日の回数上限を使います。

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | キー未設定で開く | 設定欄が開き、黄色のメッセージが出て、「検索」ボタンが押せない |
| 2 | キーを入れて「保存」 | 「APIキーを保存しました」と出て、「検索」が押せる。再読み込みしても設定済みのまま |
| 3 | `ENEOS 丸の内` で検索 | 「〇件見つかりました」と出て、基本情報・地図・ストリートビューが表示される |
| 4 | 候補の「この店舗を表示」 | 上の表示がその店舗に切り替わり、ボタンが「表示中」になる |
| 5 | 「比較に追加」を3件 | 比較欄に3件並ぶ。4件目は「3件までです」と出る |
| 6 | 比較の × | その店舗が比較から外れる |
| 7 | 「最近の検索」を開いて押す | 同じ言葉で再検索される。20件まで残り、再読み込み後も残る |
| 8 | 「履歴を消す」 | 履歴が空になる |
| 9 | 店舗カードの ☆ | ★ になり、「お気に入り一覧」に追加される。もう一度押すと外れる |
| 10 | お気に入りの店名を押す | その店舗が表示される（検索はしない） |
| 11 | 「エクスポート」→ 別のブラウザで「インポート」して貼り付け →「読み込む」 | 同じお気に入りが追加される |
| 12 | スマホ幅（約 375px）で表示 | すべて縦1列になり、横にはみ出さない |
| 13 | 「APIキー設定」→「消去」 | 未設定に戻り、「検索」が押せなくなる |

### うまくいかないとき

| メッセージ | 主な原因 |
|---|---|
| APIキーが正しくありません | キーの貼り付け間違い |
| このキーは使えませんでした | ウェブサイトの制限に今の URL が入っていない／Places API (New) が無効／請求先アカウントが無効 |
| 今日の検索回数の上限に達しました | 1日の回数上限に到達。太平洋時間の0時（日本時間の夕方）に戻る |
| 通信できませんでした | インターネット接続を確認 |

詳しい原因は、ブラウザの開発者ツール（F12）の「Console」に英語で出ています。

## ファイル構成

```
docs/                 GitHub Pages で公開するアプリ本体
  index.html          画面
  styles.css          見た目（色は CSS 変数で管理）
  app.js              画面の操作と各処理をつなぐ
  config.example.js   config.js のお手本
  lib/
    api.js            Google（Places API / Maps Embed API）との通信
    storage.js        ブラウザへの保存（APIキー・履歴・お気に入り）
    ui.js             基本情報・地図などの表示
    lists.js          候補一覧・比較・履歴の表示
    key.js            APIキーの決定と設定欄
    favorites.js      お気に入り
REQUIREMENTS.md       要件仕様書
CLAUDE.md             Claude Code 用の開発ルール
```

### ブラウザに保存するデータ（LocalStorage）

| 名前 | 中身 |
|---|---|
| `GMAPS_API_KEY` | API キー |
| `SS_FINDER_HISTORY` | 検索履歴（最大20件） |
| `SS_FINDER_FAVORITES` | お気に入り |
